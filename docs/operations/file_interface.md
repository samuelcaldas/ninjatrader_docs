# File Interface

|  |
| --- |
| File Interface Overview  The File interface is an easy way you can instruct NinjaTrader to place and manage orders. To use this interface, just create Order Instruction Files (OIFs) in "My Documents\<NinjaTrader Folder>\incoming" and when NinjaTrader sees the instructions they will be processed immediately. This interface allows you the flexibility to create order instructions to NinjaTrader from any application that allows you to create text files.
