# AllTrades

## Definition

A [TradeCollection](tradecollection.md) object of all trades generated by a strategy.

## Syntax

SystemPerformance.AllTrades

## Examples

![Ns](../images/ns.png)

```csharp
protected override void OnBarUpdate()
{
    // Print out the number of long trades
    Print("The strategy has taken " + SystemPerformance.AllTrades.Count + " trades.");
}
```
