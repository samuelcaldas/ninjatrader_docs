NinjaScript provides a number of methods and properties useful for analyzing and identifying specific conditions within [Series<T>](seriest-1.htm) collections. Some of these methods test a condition and return true or false, while others return an int-based bar index or other numerical value. A list of analytical methods can be found below:

Methods and Properties
----------------------

|  |  |
| --- | --- |
| [CountIf()](countif-1.htm) | Counts the number of occurrences of the test condition |
| [CrossAbove()](crossabove-1.htm) | Evaluates a cross above condition |
| [CrossBelow()](crossbelow-1.htm) | Evaluates a cross below condition |
| [GetCurrentAsk()](getcurrentask-1.htm) | Returns the current Ask price |
| [GetCurrentAskVolume()](getcurrentaskvolume-1.htm) | Returns the current Ask volume |
| [GetCurrentBid()](getcurrentbid-1.htm) | Returns the current Bid price |
| [GetCurrentBidVolume()](getcurrentbidvolume-1.htm) | Returns the current Bid volume |
| [GetMedian()](getmedian-1.htm) | Returns the median value of the specified series |
| [HighestBar()](highestbar-1.htm) | Returns the number of bars ago the highest price value occurred |
| [IsFalling()](falling-1.htm) | Evaluates a falling condition |
| [IsRising()](rising-1.htm) | Evaluates a rising condition |
| [Least Recent Occurrence (LRO)](least_recent_occurence_lro-1.htm) | Returns the number of bars ago that the least recent occurrence of a test condition evaluated to true |
| [LowestBar()](lowestbar-1.htm) | Returns the number of bars ago the lowest price value occurred |
| [Most Recent Occurrence (MRO)](most_recent_occurence_mro-1.htm) | Returns the number of bars ago that the most recent occurrence of a  test condition evaluated to true |
| [Slope()](slope-1.htm) | Returns a measurement of the steepness of a price series measured by the change over time |
| [TickSize](ticksize-1.htm) | The value of 1 tick for the corresponding instrument |
| [ToDay()](today-1.htm) | Calculates an integer value representing a date |
| [ToTime()](totime-1.htm) | Calculates an integer value representing a time |
