# RealTimeTrades

## Definition

RealTimeTrades is a [TradeCollection](tradecollection.md) object of real-time trades generated by a strategy.

## Syntax

SystemPerformance.RealTimeTrades

## Examples

![Ns](../images/ns.png)

```csharp
protected override void OnBarUpdate()
{
    // Print out the number of real-time trades
    Print("The strategy has taken " + SystemPerformance.RealTimeTrades.Count + " real-time trades.");
}
```
