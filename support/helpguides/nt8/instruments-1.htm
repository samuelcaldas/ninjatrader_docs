Instruments

Instruments Window Overview

The Instruments window can be accessed by left mouse clicking on the Tools menu within the NinjaTrader Control Center and selecting the menu item Instruments.

NinjaTrader supports multiple connectivity providers and therefore manages a single instrument instance (master instrument) which maintains the parameters required to establish market data and order permissions through the various connectivity sources. The Instruments window manages the instrument data and can add or remove instruments from the database. NinjaTrader maintains a predefined database of commonly traded instruments on our server and your local database is updated automatically on NinjaTrader application startup.
